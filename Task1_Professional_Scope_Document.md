# Task 1 – Professional Scope Document

## Project Title
Tomato Shelf-Life Prediction Using AI

## Objective
Develop an AI-based model to predict tomato spoilage using image data collected under different storage conditions and tome.

## Deliverables
- Image dataset of tomatoes
- Cleaned dataset
- Exploratory Data Analysis (EDA)
- Machine Learning model
- Final report and presentation

## Scope
This project includes data collection, preprocessing, exploratory analysis, model development, and evaluation. It does not include mobile application development or commercial deployment.

## Milestones
1. Literature Review
2. Data Collection
3. Data Cleaning
4. Exploratory Data Analysis
5. Model Development
6. Model Evaluation
6. Final Report and Presentation
